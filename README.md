# Prompts Manager

A beautiful web app to manage your prompts with categories, search, and cloud storage.

## Features
- Add, edit, delete prompts
- Organize by categories
- Copy prompts with one click
- Cloud storage with MongoDB
- Responsive design

## Tech Stack
- React + Tailwind CSS
- Node.js + Express
- MongoDB Atlas
- Vercel

## Getting Started
```bash
npm install
npm run dev
```
